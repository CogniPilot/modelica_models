ESKF semi-direct bias correction comparison, 7 October 2026
==========================================================

The experimental bias-aware local correction is integrated and independently
validated, but produces small, mixed accuracy changes on the fixed-data
campaign. It does not make ESKF outperform native PX4 EKF2 and ArduPilot EKF3
across all scenarios. useSemiDirectBias remains false by default. The large
startup improvement belongs to the preceding declared-rest change, not this
new correction geometry.

eskf-semidirect.html compares the new correction against native EKF2/EKF3;
eskf-semidirect-alignment.html and eskf-semidirect-vector.html retain both
geometry ablations. Each chart includes all GPS, GPS-denied, GPS loss/return,
rate, arrival-delay and scoring-window combinations with three-seed ranges.
eskf-semidirect-ablations.csv contains 6048 per-seed/window rows joining the
three preceding stationary options, their three semi-direct counterparts and
the unchanged native runs. No best-per-case configuration is selected.

Experiment and scope
--------------------

There are 648 new performance replays: three correction/geometry options,
two fusion modes, three scenarios, two rates, three delays, and two independent
three-seed motion sets. Original motion is .6 rad/s with seeds 7/19/41; held-out
motion is .85 rad/s with seeds 101/307/911. Flight scoring uses 13 <= t < 60 s;
GPS loss uses measurement timestamps 25 <= t < 40 s. Sensor rates are
100/50/50 Hz or 25/25/25 Hz flow/mag/barometer, with the same 800 Hz IMU,
10 Hz GPS and 100 Hz output scoring. Retrodiction and the generated-component
fusion horizon both receive the explicit stationary phase until 13 s; the
horizon evaluates rest at its delayed IMU epoch.

All captures, arrival parameters and native filter pins remain unchanged.
Every ESKF delivery count and payload digest matches the native transport
trace. The exact 216 earlier native runs are reused, not rerun. The native
cores are validation submodules, not copied into this repository. Priors,
noise tuning, source selection and native output observers remain specific
to each stack; this is a configured-stack comparison, not a universal ranking.
See native-delay.txt and native-delay-manifest.json for the native audit,
source pins, time interpretation and interpolation rules.

Implementation and mathematical limits
--------------------------------------

All correction wrappers, including alignment, GPS position/velocity, mocap,
flow, barometer, magnetometer and stationary/pseudo constraints, forward one
disabled-by-default option. The local group has 15 physical states,
SE_2(3) semidirect se(3). With translation-first beta=(accelerometer bias,
gyroscope bias), the mean update is

  T_new = T Exp_SE23(delta_position, delta_velocity, delta_rotation)
  beta_new = beta + Jr_SE3(delta_velocity, delta_rotation) delta_beta.

A pose-only correction preserves the existing physical biases. The full
15x15 reset includes the pose-to-bias derivative and the bias right Jacobian,
not just the former nine-state pose reset. A twelve-term array-based derivative
series is checked in the actual .15 rad attitude-correction trust region.
The generic Joseph update includes both state/measurement-noise cross terms
when the observation is correlated with the prior state.

The preceding helper report eskf-semidirect-bias-design.txt records the group
action, finite-difference reset and continuous coordinate-transform derivation.
Its historical statement that helpers were not yet integrated applies to that
earlier stage only. Existing physical IMU propagation, FOH covariance and
first-order local observation maps are retained here: the retraction has the
same first derivative at zero. This is a consistent local correction-chart
experiment, not an implementation of the 18-state tangent-group filter,
exact nonlinear bias propagation, or a completed equivariant observer.

Generated-code covariance fix
------------------------------

An independent Gaussian-kernel test found a covariance mismatch in a generic
three-dimensional heading-constrained update, although its mean agreed with
the reference. Materializing the projected and trust-limited gain through
constrainGain (Inline=false) fixes the generated evaluation. The same effective
gain now serves both the mean and Joseph covariance update. This also makes
the projection and trust-limit code a compact, readable array expression.

With seed 20261007, the retained pre-fix generated library fails with maximum
normalized covariance error .302493638; the corrected library is below
1.1e-5. This test exposes a generic vector-heading path; it does not establish
that all previous scalar-heading flight corrections were affected. Replays
with the new option disabled are separately checked for exact compatibility.

Covariance consistency
----------------------

rates, both motion sets and all seeds in nominal-delay denied flight. All
4700 scored rows per replay admit a positive Cholesky factor and are symmetric.

Validation and remaining gaps
------------------------------

All 648 preceding stationary outputs (base, alignment and vector variants)
are byte-identical with the new option disabled. All 216 earlier default,
rest-disabled outputs are also byte-identical. This separates the semi-direct
accuracy changes from the gain materialization/compiler workaround.

The independent generated-C correction check passes 1440 configurations across
two fixed seeds. It includes both geometries, unrestricted/projected/heading
gains, correlated noise, attitude trust limits, positive covariance and exact
mean/covariance preservation on rejection. The helper group/reset/dynamics
checks remain separate. The C aiding fixture passes 24 configurations, including
both correction options, geometry combinations, simultaneous aiding and rest,
health counters, release and invalid variance refusal. The horizon adapter
fixture passes delayed rest-epoch and sensor-configuration checks.

OpenModelica simulations pass for StationaryAidingTests, MultisensorAidingTests,
and experimental heading/vector stationary variants. Rumoca 0.10.2 lowers
Tests.All to canonical DAE. The CI code now exports the correction probe and
runs both independent seeds. The composed horizon still reaches the same
recorded ED020 sampled-read boundary at HorizonEstimator.mo:259:5; added
configuration shifts identity 577 to 578, not a resolved compiler boundary.
Interactive chart checks cover 576 selections per report. Source history
remains uncommitted; full mission qualification, complete local/remote CI,
fresh native-core rebuilding and flight-target timing were not run here.

The remaining accuracy gap is primarily denied-flight velocity/heading and
robustness, not a missing finite bias retraction. Next experiments should
isolate magnetic heading versus tilt/bias information, optical-flow/gyro/range
correlation, and excitation-dependent bias observability. Current-output
observer design is a separate accuracy/latency/smoothness tradeoff. Add magnetic
disturbances, range faults, rapid rotations and vibration before promoting any
geometry or claiming a general flight advantage. Existing preintegration
savings and host timing do not establish flight-target WCET or RAM superiority.

Reproduction
------------

Use a new owned directory under $HOME/scratch for builds and evidence. Run
build.py --eskf-only --horizon --semi-direct-bias with pinned Rumoca 0.10.2.
Repeat with --geometric-alignment, then with that flag and
--equivariant-magnetometer. compare_delay.py --stationary-until 13
--repetitions 1 uses the three arrival profiles. Original arguments are
--frequencies .6 --seeds 7 19 41; held-out arguments are --frequencies .85
--seeds 101 307 911. Keep capture inputs unchanged.

For independent kernel checks, export Tests.SemiDirectBiasCorrectionReplay
with --target galec-production; compile semidirect_correction.c with the
exported model and rumoca_galec_kernels.c into a C99 float32 shared library.
Run check_semidirect_correction.py --library LIBRARY --output NEW_JSON and
repeat with --seed 911. tools/ci.py runs this same check through the normal
Rumoca CI entry point. For covariance diagnostics run evaluate.py on the
retrodiction binary with --scenarios denied --diagnostics --delay-profile
nominal --stationary-until 13 --gyro-bias .0008 -.0005 .0004
--accel-bias .02 -.01 .015 and the same frequency/seeds.

Use report_native_delay.py --eskf-prefix eskf-semidirect (or its alignment/vector
suffix) --review-prefix eskf-semidirect to recreate the corresponding HTML/CSV.
The manifest fingerprints source, generated code, binaries and review evidence;
earlier-stage manifests remain historical snapshots.
