Semi-direct bias geometry: implementation probe, 7 October 2026
==============================================================

Status: the Modelica injection and full reset Jacobian are implemented in
Estimation.StrapdownINS.ESKF.SemiDirectBias and checked through Rumoca 0.10.2
production C. They are experimental helpers, not connected to the production
ESKF correction path. No estimator-performance improvement is claimed for
these helpers. The completed startup comparison is eskf-stationary.txt.

The candidate group is SE_2(3) semidirect se(3), retaining 15 physical states.
This choice is described in section 5.6 and appendix B.6 of Fornasier et al.,
Equivariant Symmetries for Inertial Navigation Systems, version 3:
https://arxiv.org/html/2309.03765v3#S5.SS6

The formulas and checks below are an independent derivation, with the
repository's position/velocity/rotation tangent order and translation-first
SE(3) helpers. They must not be confused with the 18-state tangent-group
filter, which introduces an additional virtual bias.

Coordinates and injection
-------------------------

Let T=(R,p,v) denote the nominal extended pose and B=(R,v) its SE(3)
projection. Biases are physical body-frame quantities. For the six-dimensional
formulas below, beta=(accelerometer bias, gyroscope bias), matching the
translation-first SE(3) convention. The public ESKF tangent still orders
position, velocity, rotation, gyroscope bias, accelerometer bias. The
conversion is explicit in the Modelica helpers.

For a local correction (eta_p,eta_v,eta_R,delta_beta), the candidate injection
is

  T_new    = T Exp_SE23(eta_p,eta_v,eta_R)
  beta_new = beta + Jr_SE3(eta_v,eta_R) delta_beta.

The pose injection is identical to the current ESKF. A pose-only correction
leaves the nominal physical biases unchanged. The bias increment is coupled
to the velocity and rotation increment; rotating the entire old bias vector
would implement a different action.

An independent global group check represents the lifted estimate as
X=(T,-Ad_B beta). The same corrected physical state is obtained from

  X_new = Exp_group(M delta) X,
  M     = diag(Ad_T,-Ad_B).

The probe computes both paths separately. It does not merely compare the
same injection formula with itself.

Full covariance reset
---------------------

The local reset Jacobian must contain both the bias Jacobian and the
pose-to-bias derivative:

  J_reset = [ Jr_SE23(eta)                       0       ]
            [ d(Jr_SE3(eta_v,eta_R) delta_beta)/d eta   Jr_SE3 ].

The lower-left block has zero position columns. Omitting it while coupling
the bias mean would leave the covariance inconsistent with the chosen local
chart. The implementation differentiates the right-Jacobian power series
using six-dimensional arrays:

  A = ad_SE3(eta_v,eta_R), w_0 = delta_beta, D_0 = 0
  D_k = A D_(k-1) - ad_SE3(w_(k-1))
  w_k = A w_(k-1)
  derivative = sum_k (-1)^k D_k / (k+1)!.

The Modelica helper uses twelve terms. It reuses the existing closed-form
SE(3)/SE_2(3) Jacobians for diagonal blocks. The derivative series is intended
for the existing correction trust region, not unrestricted rotations.
The probe also includes exactly zero and tiny rotations and zero correction.

Propagation consistency
-----------------------

An independent differential check transforms the current body-tangent error
matrix using

  A_global = (M A_body + dM/dt) inverse(M).

In global coordinates, with gyro/accelerometer bias-error components denoted
beta_w/beta_a, it reproduces

  dot epsilon_R = beta_w
  dot epsilon_v = gravity_cross epsilon_R + beta_a
  dot epsilon_p = epsilon_v + position_cross beta_w.

The bias block is ad_SE3(world acceleration + velocity cross world rate,
world rate) in translation-first order. This establishes the first-order
coordinate relation, not a completed discrete stochastic filter. Noise maps,
measurement maps, bias ordering, finite correction reset, held-input
covariance and forward output rebasing must remain consistent when the
helpers are integrated. Reusing physical propagation requires this relation;
it is not justified by changing the retraction alone.

Validation and limits
---------------------

check_semidirect_bias.py checks 120 configurations for each of seeds 20261007
and 911. It independently checks group multiplication, finite-difference
reset derivatives, and the continuous dynamics coordinate transform. With
--library, it calls the actual Rumoca-generated correction/reset helpers
through semidirect_bias.c and compares float32 outputs with the independent
NumPy implementation. The two generated-probe JSON files retain all maxima.
Pose-only corrections are checked to preserve physical biases exactly.

The exported probe succeeds after materializing the complete output record.
An initial output-record assignment followed by partial field assignments
hit Rumoca ED019 record-output assembly; the explicit complete constructor
avoids this compiler boundary. The production estimator has not been altered
by these helper additions. They have not yet been assessed on GPS, denied,
return, covariance consistency, output smoothness or efficiency.

Next integration is the generic correction kernel's mean and full covariance
reset, followed by all aiding wrappers under a disabled-by-default option.
Preserve the current component source snapshot and score files as the startup
baseline. Retest default-off identity, consider-mode semantics, correlated
noise corrections, covariance definiteness and independent held-out delayed
replays before selecting any production default.

Reproduction
------------

Use an owned project directory under $HOME/scratch. Export
Tests.SemiDirectBiasReplay with Rumoca 0.10.2, --cache-dir CACHE --source-root .
--target galec-production --output EXPORT. Compile semidirect_bias.c with the
generated Tests_SemiDirectBiasReplay.c and rumoca_galec_kernels.c, using
-std=c99 -O2 -shared -fPIC -I PRODUCTION_CODE -lm -o LIBRARY.
Run check_semidirect_bias.py --library LIBRARY --output NEW_JSON and repeat
with --seed 911. Existing evidence must remain unchanged.
