Pressure consider covariance in the right-local navigation tangent
=================================================================

Let e be the 15D navigation error, b the scalar datum error, P=Cov(e),
c=Cov(e,b), and B=Var(b). The datum mean is held after startup calibration.
For a linearized observation r=H e+v, write C=Cov(e,v), d=Cov(v,b), R=Cov(v).
Then

  S = H P H' + H C + C' H' + R
  K = (P H' + C) S^-1
  e+ = (I-KH)e - K v
  c+ = c - K(Hc+d)

The existing constrained-gain and attitude-trust logic may replace K.
The generalized Joseph update remains the covariance of that linear map
for the resulting gain. The datum gain row is zero, so B remains unchanged.
The full navigation/datum posterior is formed by a congruence of the joint
covariance of (e,b,v); it is PSD when that prior joint covariance is PSD.
The square-root implementation uses the same conditional noise factors as
the existing correlated correction. It does not form a 16x16 navigation
root or repair failed covariances.

For pressure, v=b_observation+n, with independent white noise n. For an
ordered random-walk datum with diffusion q and observation age tau,

  B_observation = B_current - q*tau
  R = B_observation + R_pressure
  C = c
  d = B_observation

This C=c assumes navigation has only fused older pressure observations and
is independent of the subsequent datum increments. It is not a generic
out-of-sequence smoothing rule. Negative observation variance or timestamp
outside the aiding window rejects the correction. Invalid nonfinite
nuisance parameters can also trigger the generated runtime's arithmetic
fault signal; they are outside the finite-parameter mathematical contract.

For other sensors, d=0 assumes observation noise independent of the datum.
Their existing C may be nonzero, for example for correlated IMU noise.
After a right-local Lie injection/reset J, c becomes J*c+. The same full
semi-direct reset or block SE_2(3)/bias reset used for P is used for c.
Prediction maps c through its existing state transition F; independent
process noise adds to P and B but not c. A covariance-limit rescaling D
also rescales c. Independent covariance inflation preserves c. Reseeding
the first six states clears their datum correlation and retains the rest.
Initialization starts with c=0 under an independent declared initial prior.

Startup pressure packets used for datum learning are withheld from
navigation, keeping that independence assumption explicit. The optional
timestamp-aware scalar update learns B_observation and adds q*tau back to
the current variance. It needs known initial altitude and valid initial
rest assumptions; using the current navigation height to learn the datum
from the same sample would need a different joint update.

PressureDatumAudit.lean verifies that the datum gain row is zero and
instantiates gnc_lean's conditional_factor_positive_semidefinite theorem
with a 16D state. The axiom audit lists only propext, Classical.choice and
Quot.sound. It proves the conditional real-arithmetic covariance property,
not exact nonlinear uncertainty, generated-C correctness, temporal
decorrelation or an error bound for the flight estimator. Floating-point
agreement is checked separately against a full augmented Gaussian Joseph
reference, including its cross-covariance block and reset.

The existing gain_gap_positive_semidefinite theorem shows that an optimal
gain has no larger linearized posterior covariance than a constrained gain
when both use the same valid covariance model. Consequently a frozen datum
gain cannot be used to claim superiority over full joint bias estimation.
The repeated-pressure example converges near variance 0.20542 from P=1,
B=0.25 and R_white=0.01, rather than the fully estimated limiting 0.2.
It is consistent covariance bookkeeping, not universal optimality.

Primary references for the standard consider-filter interpretation:
Zanetti and D'Souza, Recursive Implementations of the Consider Filter (2012),
https://ntrs.nasa.gov/citations/20120010515
Carpenter and D'Souza, Navigation Filter Best Practices (2018),
https://ntrs.nasa.gov/citations/20180003657
The first explicitly discusses recursive consider-filter non-optimality.
