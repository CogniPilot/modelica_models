Joint datum correction in block form
===================================

Let x be the 15D navigation tangent error, b the scalar world pressure-datum
error and v the observation noise. Write Cov(x)=P, Cov(x,b)=c, Var(b)=B,
Cov(x,v)=C, Cov(v,b)=d and Cov(v)=R. The innovation is H*x+v with covariance
S=H*P*H' + H*C + C'*H' + R. Its datum cross covariance is u=H*c+d.

The existing innovation factorization solves navigation gain, residual/NIS
and datum gain k_b=S^-1*u together. Navigation gain K retains the existing
heading/trust constraints. Let A=I-K*H and t=-H'*k_b. Compute vectors

  navigationColumn = P*t + c - C*k_b
  noiseColumn      = C'*t + d - R*k_b
  datumColumn      = c'*t + B - d'*k_b

The augmented Joseph congruence then gives

  c_next = A*navigationColumn - K*noiseColumn
  B_next = t'*navigationColumn + datumColumn - k_b'*noiseColumn
  mean_b_next = mean_b + k_b'*residual.

This block formula remains valid for constrained navigation gain K. The
simplified optimal-gain covariance subtraction is not valid in general for
those constraints. A rejected update preserves the prior datum state. The
existing navigation covariance/root update is unchanged for a given prior.
After nominal-state injection, the same navigation reset Jacobian maps c;
the additive world datum variance does not change under that coordinate reset.

Pressure residuals subtract the current estimated datum mean. For ordered
delayed pressure observations, B_obs=B_current-q*age, R=B_obs+white_variance,
C=c and d=B_obs. This requires independent subsequent datum random-walk
increments and valid ordered timestamps. Independent aiding uses C=d=0 but
can still update b through H*c. This is not a general out-of-sequence smoother.
The Estimator applies scalar process diffusion once per sample, retains joint
posteriors between ticks, and uses the same startup calibration/withholding
policies selected in each paired comparison.

Formal scope
------------
The gnc_lean gain-gap theorem proves P(K)-P(K_opt)=(K-K_opt)*S*(K-K_opt)' is
PSD when S is PSD and K_opt*S is the state/innovation cross covariance. A
common reset congruence preserves that order. This conditional optimality is
for the full augmented linearized model. With a constrained navigation gain,
the implementation's full gain need not meet that hypothesis. A smaller datum
variance alone does not imply Loewner dominance of the full joint covariance.
The arbitrary-gain Joseph PSD result instead assumes a valid joint covariance
factorization. Neither theorem bounds nonlinear flight RMS against native
EKF2/EKF3 with unequal effective noise, priors and aiding policies.
