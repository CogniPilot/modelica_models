# Project guides

Library help lives in Modelica `Documentation(info=...)` HTML. Open a package
or component's documentation in your Modelica tool; its parameter declarations
and links are the API reference.

Useful entry points are [`Estimation.StrapdownINS`](../Estimation/StrapdownINS/package.mo),
[`Estimation.FusionHorizon`](../Estimation/FusionHorizon/package.mo),
[`SLAM`](../SLAM/package.mo) and
[`SLAM.Simulation.LandmarkCamera`](../SLAM/Simulation/LandmarkCamera.mo).

These guides cover work outside the library:

- [Publish the Modelica reference](publishing.md): local preview and GitHub Pages workflow.
- [Run validation](validation.md): repository checks and visual replay commands.
- [Export SLAM for a browser consumer](slam-export.md): versioned compatibility snapshots.
- [Estimator licensing](licensing.md): source and distribution boundaries.

See the [tooling index](../tools/README.md) for automation and
[CONTRIBUTING.md](../CONTRIBUTING.md) for package conventions and contributor checks.
